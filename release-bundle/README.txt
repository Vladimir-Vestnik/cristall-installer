Кристалл — комплект для установки (Windows)
============================================

В папке должны быть:
  • Cristall-ElectronBuilder-Setup-1.0.0.exe  — установщик программы
  • README.txt                                — этот файл (прочитайте до установки)
  • VIA_Zodiak_-_Polyot_k_zvyozdam.mp3        — рингтон для звонков (по желанию)

Требования
----------
  • Windows 11, 64-bit; возможно и на Windows 10, 64-bit, но не тестировалось.
  • Свободное место на диске (ориентир: от 2 ГБ с учётом базы и вложений)
  • Интернет — для регистрации, почтовых кодов и работы сети узлов

Установка
---------
  1. Закройте Кристалл, если он уже был установлен ранее.
  2. Запустите Cristall-ElectronBuilder-Setup-1.0.0.exe.
  3. Папка по умолчанию:
     C:\Users\<ваш_пользователь>\AppData\Local\Programs\electron-cristall
  4. Дождитесь окончания установки. Ярлык — в меню «Пуск» и на рабочем столе.

При переустанов поверх старой версии сохраняются: база данных, загрузки (uploads),
настройки (.env), идентичность узла в сети. Перед установкой программу лучше закрыть.

Первый запуск и регистрация
---------------------------
  1. Запустите «Кристалл».
  2. Если аккаунта нет — «Зарегистрироваться».
  3. Укажите телефон, подтвердите код, заполните профиль.
  4. Отметьте согласие с условиями использования платформы.
  5. Дождитесь зелёного сообщения "Сеть аккаунтов: Подключение к эталонному узлу подтверждено. Реестр получен. Регистрация доступна." 
  кликните на "Зарегистрироваться".
  6. Вход в приложение по указанным при регистрации телефону и паролю.
Сеть
----
  После входа откройте настройки модалки сети (клик на значёк «Сеть Кристалл» в правом вехнем углу приложения): 

  1. Вариант подключения к relay (централизованное подключение узлов) вставив в поле модалки "Адрес узла-партнёра (ip:порт или алиас):"
  ссылку - ws://176.53.162.12:7777
  2. Вариант децентрализованного подключения к сети в тоже поле модалки "Адрес узла-партнёра (ip:порт или алиас):" вставить 
  ссылку - Cristall.ved. 

Личный кабинет
--------------
  Профиль, смена пароля, диагностика и логи — в левой панели ЛК.
  Полное руководство — ссылка «Руководство пользователя» внизу левой панели (после
  обновления программы).

Основные разделы
----------------
  • Вечевая структура — предложения, обсуждения, голосования
  • Ресурсный блок — объявления и ресурсы
  • Текстовый Мессенджер — сообщения (в личном кабинете) 
  • Аудио/видео Мессенджер в виде модалки 

Роли (кратко)
-------------
  • Гость — просмотр в рамках выданных прав
  • Вечник — участие в обсуждениях и голосованиях
  • Исполнитель — работа с поручениями и исполнением решений
  Подробнее — в «Руководстве пользователя» в программе.

Рингтон (файл mp3 из комплекта)
-------------------------------
  Программа не использует mp3 из папки установки. Сделайте так:

  1. Зарегистрируйтесь и войдите хотя бы один раз.
  2. Найдите папку (обычно):
     Документы\Архив Кристалл\<Имя>_<Фамилия>\ringtones\
     При синхронизации OneDrive путь может начинаться с OneDrive\Documents\...
  3. Скопируйте VIA_Zodiak_-_Polyot_k_zvyozdam.mp3 в папку ringtones.
  4. В Кристалле: Модалка звонков → Настройки → выбор рингтона для звонка — укажите этот файл.
