# История изменений «Кристалла»

В этом документе перечислены изменения, заметные пользователю или влияющие на совместимость узлов.

## 0.1.5 — 03.11.2026

### Добавлено

- Передача фактической версии узла из `network/app-version.json`.
- Запись номера собираемой версии в сетевые метаданные программы.
- Пометки полного удаления предложений, которые не позволяют удалённой карточке вернуться после подключения узла, находившегося вне сети.
- Передача пометок полного удаления при полном обмене данными между узлами.

### Исправлено

- Для чистой установки настроен постоянный канал проверки обновлений без ручного добавления адреса в `.env`.
- Ранее установленные копии со старым адресом манифеста переводятся на постоянный канал обновлений.

## 0.1.4 — 29.10.2026

### Исправлено

- Синхронизация текста тематики предложения между узлами.
- Определение совета предложения по территориальному пути вместо локального номера строки.
- Обновление ленты без перезапуска страницы после изменения тематики или совета предложения.

### Изменено

- Добавлен протокол обмена базой `sync_protocol = 1`.
- Несовместимые версии узлов больше не отправляют друг другу пакеты базы предложений.
- Регистрация, вход и необходимый служебный обмен с прежними узлами при этом не блокируются.

## 0.1.3 — 27.10.2026

### Добавлено

- Отображение хода скачивания обновления: проценты и объём полученных данных.
- Окно подтверждения перед закрытием программы и запуском установщика.

### Исправлено

- Запуск помощника обновления после завершения основного процесса программы.
- Ожидание полного выхода «Кристалла» перед запуском Setup.exe.
- Сообщения о завершении скачивания, закрытии программы и последующем запуске установщика.

## 0.1.2 — 27.10.2026

- Техническая повторная сборка.
- Функциональный код совпадает с версией `0.1.1`; изменён только номер версии.

## 0.1.1 — 27.10.2026

### Добавлено

- Скачивание нового Setup.exe непосредственно из программы.
- Проверка контрольной суммы SHA-256 скачанного установщика.
- Удаление неполного или повреждённого установщика.
- Сохранение установщика вне каталога установленной программы.
- Помощник, ожидающий завершения «Кристалла» и запускающий Setup.exe.
- Запуск обновления по кнопке в уведомлении о доступной версии.

## 0.1.0 — 26.10.2026

### Добавлено

- Упорядоченная тестовая линейка версий `0.1.x`.
- Отображение текущей версии программы.
- Проверка наличия новой версии по файлу `latest.json`.
- Полоса с уведомлением «Доступна новая версия».
- Автоматическое повышение номера для следующей версии после успешной сборки.

В этой сборке установка обновления непосредственно из программы ещё отсутствовала.

## Исторический предрелиз 1.0.0 — 29.06.2026

- Создан первый публичный канал установки «Кристалла» на GitHub.
- Номер `1.0.0` был выбран как условный номер первого предрелиза.
- После него проект перешёл на последовательную тестовую нумерацию `0.1.x`.
