# Кристалл — установка и обновление

## Скачивание

Установочные файлы публикуются на странице [Releases](https://github.com/Vladimir-Vestnik/cristall-installer/releases).

Откройте самый новый выпуск линейки `0.1.x` и скачайте файл:

```text
Cristall-ElectronBuilder-Setup-*.exe
```

Версии `0.1.x` являются предварительными, поэтому для их скачивания следует использовать общую страницу Releases, а не ссылку `Releases / latest`.

## Системные требования

- Windows 10 или Windows 11, 64-разрядная версия.
- Не менее 2 ГБ свободного места с учётом базы данных и вложений.
- Подключение к интернету для регистрации, получения кодов подтверждения, работы сети узлов и обновления программы.

## Установка

1. Если «Кристалл» уже запущен, закройте программу.
2. Запустите установщик `Cristall-ElectronBuilder-Setup-*.exe`.
3. При необходимости измените папку установки. Путь по умолчанию:

   ```text
   C:\Users\<имя_пользователя>\AppData\Local\Programs\electron-cristall
   ```

4. Дождитесь окончания установки.
5. Запустите «Кристалл» с рабочего стола или из меню «Пуск». На последней странице установщика также можно оставить включённой команду запуска программы.

При установке новой версии поверх прежней сохраняются:

- база данных и зарегистрированные аккаунты;
- загруженные файлы и вложения;
- настройки программы;
- настройки подключения;
- идентичность узла в сети.

## Первый запуск и регистрация

1. Запустите «Кристалл».
2. На странице входа нажмите «Зарегистрироваться».
3. Укажите фактические ФИО, свой адрес проживания, номер телефона и адрес электронной почты.
4. Получите и введите код подтверждения.
5. Заполните персональные данные и создайте пароль.
6. Ознакомьтесь с условиями использования платформы и подтвердите согласие.
7. Дождитесь сообщения:

   > Сеть аккаунтов: подключение к эталонному узлу подтверждено. Реестр получен. Регистрация доступна.

8. Нажмите «Зарегистрироваться».
9. После завершения регистрации войдите по номеру телефона и паролю.

Для регистрации необходимо соединение с эталонным узлом и получение актуального реестра аккаунтов.

## Подключение к сети «Кристалл»

После входа нажмите значок «Сеть Кристалл» в правом верхнем углу программы.

В поле «Адрес узла-партнёра (ip:порт или алиас)» можно указать один из вариантов:

### Подключение через relay

```text
ws://176.53.162.12:7777
```

### Децентрализованное подключение

```text
Cristall.ved
```

Индикатор и надпись «Сеть: …» в верхней части окна показывают текущее состояние подключения. Без соединения с сетью недоступны синхронизация и обмен данными между узлами.

## Основные разделы

- **Личный кабинет** — персональные данные, размещение в вечевых структурах, участие в социальных процессах, вклад в сообщество и настройки.
- **Вечевая структура** — предложения, обсуждения, комментарии, коллективное редактирование и голосования.
- **Ресурсный блок** — объявления о ресурсах и услугах, категории и местоположение.
- **Поиск пользователей** — анкеты участников и добавление личных контактов.
- **Текстовый мессенджер** — личные и групповые сообщения, отправка изображений, аудио, видео и документов.
- **Аудио- и видеосвязь** — личные и групповые звонки, настройка камеры, микрофона и рингтона.

В нижней части левой панели личного кабинета находятся:

- руководство пользователя;
- условия использования платформы;
- политика конфиденциальности;
- контакты службы поддержки.

## Статусы участников

- **Гость** — начальный статус нового участника с ограниченными правами.
- **Вечник** — подтверждённый участник, который может полноценно участвовать в предложениях, обсуждениях и голосованиях.
- **Исполнитель** — участник с полномочиями для выполнения решений и работы с административными функциями в пределах назначенных прав.

Статус Вечника присваивается после получения необходимых рекомендаций от подтверждённых участников.

## Обновление программы

«Кристалл» проверяет наличие новой версии и показывает уведомление, когда обновление становится доступно.

Обновить программу можно из уведомления либо вручную:

1. Откройте **Личный кабинет → Настройки → О программе**.
2. Нажмите «Проверить обновление».
3. Если доступна новая версия, нажмите «Установить обновление».
4. Дождитесь скачивания установщика. Ход загрузки отображается в программе.
5. После скачивания программа проверит контрольную сумму SHA-256 установщика.
6. Подтвердите продолжение. «Кристалл» закроется, после чего автоматически откроется установщик новой версии.
7. Завершите установку. В конце установщик предложит снова запустить программу.

Установщик сохраняет базу данных, вложения, локальные настройки, настройки подключения и идентичность узла.

Если автоматическое обновление временно недоступно, новую версию можно установить вручную, запустив полученный `Cristall-ElectronBuilder-Setup-*.exe` поверх существующей установки. Перед ручным обновлением необходимо закрыть «Кристалл».
